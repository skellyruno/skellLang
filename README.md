# SkellLang 🩻

Skelly's experimental proprietary audio-plugin language and toolchain.

**Status:** repository bootstrap. The original `skell 1` compiler is being migrated from [SkellForge](https://github.com/skellyruno/skellforge/tree/feature/skelllang-sdk-v0.1) on a separate development branch and draft pull request. **No SkellCipher encryption is implemented yet.**

This public repository contains **compiler code only**, not private plugin source, secrets, or encryption keys. Do not commit protected projects in plaintext.

Shared rules: [SkellWorld/AGENTS.md](https://github.com/skellyruno/SkellWorld/blob/main/AGENTS.md).
