# SkellLang rules 🩻

Follow [SkellWorld/AGENTS.md](https://github.com/skellyruno/SkellWorld/blob/main/AGENTS.md).

- Never commit private encryption keys, secrets, or unencrypted protected projects.
- Preserve `skell 1`, automation IDs, preset defaults and Studio JSON v1, or provide an explicit opt-in migration.
- Use draft PRs and actual tests. Do not merge unverified changes.
- Do not overwrite SkellForge or SkellNative production code.
- `.skellenc` must fail closed until authorized SkellCipher cryptography is implemented and tested.
